# UNCHARTED: A Web-Based Soundscape Experience

This project presents a location-based soundscape system that links real-time GPS data to dynamic audio playback in a mobile web application. As users move through geographic space, musical excerpts tied to predefined node regions are triggered, blended, and faded based on proximity.

## Demo

Experience the live demo here: [nicoleytlam.github.io/soundscape-project](https://nicoleytlam.github.io/soundscape-project/)

## Features

- **Location-Aware Audio Playback**: Utilizes real-time GPS data to determine the user's location.
- **Dynamic Soundscapes**: Triggers and blends musical excerpts associated with specific geographic nodes.
- **Proximity-Based Audio Fading**: Adjusts audio playback volume based on the user's distance from predefined regions.
- **Mobile-Friendly**: Designed as a mobile web application for on-the-go experiences.

## Getting Started

### Prerequisites

- A modern web browser with geolocation support (e.g., Chrome, Firefox, Safari).
- Internet connection to access the web application and associated audio files.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/nicoleytlam/soundscape-project.git
   ```

2. Navigate to the project directory:
   ```bash
   cd soundscape-project
   ```

3. Open `index.html` in your preferred web browser.

## Usage

1. Ensure your device's location services are enabled.
2. Open the web application in your mobile browser.
3. As you move through different geographic areas, the application will play and blend musical excerpts associated with those regions. ([GitHub - soundscape-community/soundscape: An iOS application/service ...](https://github.com/soundscape-community/soundscape?utm_source=chatgpt.com))

## Project Structure

- `index.html` - Main HTML file for the web application.
- `*.mp3` - Audio files associated with specific geographic nodes.
